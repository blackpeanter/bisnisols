Tentang Aplikasi

Aplikasi ini memungkinkan Anda membuat link pelacakan lokasi yang dapat dikirimkan ke seseorang. Ketika link dibuka, lokasi pengguna akan dikirimkan secara otomatis dan dapat Anda lacak dengan kode pelacakan yang diberikan.

Teknologi ini menggunakan API Geolocation browser dan penyimpanan data sederhana di localStorage untuk demo. Untuk penggunaan nyata, Anda perlu backend untuk menyimpan dan mengelola data lokasi secara aman.
